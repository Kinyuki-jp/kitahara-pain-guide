受けるまでの4つの段どり

  1. かかりつけの先生に相談する

    「横浜市大センター病院の ペインクリニック内科、北原雅樹先生に紹介してほしい」と伝えてください。紹介状（正式には診療情報提供書）を書いてもらいます。

  2. 通っている病院ぜんぶの紹介状をそろえる

    1通ではありません。いま通っている病院すべてから紹介状が必要です。飲んでいる薬が重なっていないかを、先生が確かめるためです。

  3. 病院に紹介状をFAXしてもらう

    ペインクリニック内科は、紹介状のFAXが届いてから予約の話が進みます。かかりつけの病院の受付にお願いすれば、やってもらえます。

  4. 予約の電話を入れる

    下の番号にかけて、「ペインクリニック内科を受けたい」「できれば北原先生でお願いしたい」と伝えてください。

知っておいてほしいこと

初めての日は3時間以上かかります

  • 検査 → 問診 → 診察と続くため、半日みておいてください。付き添いの人がいると安心です。
  • 予約はとても混んでいます。病院も「予約を取るのが大変むずかしい」と案内しています。あせらず、気長に構えてください。
  • 遠方の人には、病院から「お近くの病院へ」とすすめられることがあります。治療は何度も通う形になるためです。
  • 痛みの相談を電話ですることはできません。相談は下の専用の窓口へ。
