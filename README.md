# 親の痛み外来ガイド

慢性痛の専門医・北原雅樹先生（横浜市立大学附属市民総合医療センター ペインクリニック内科）の
外来にかかるための手順を、高齢の家族が読める形にまとめたページです。

## 公開ページ

- `docs/index.html` — 受診ガイド（紹介状の取り方・電話番号・持ち物・注意点）
- `docs/videos.html` — 北原先生の動画「痛み塾」の見る順番
- `docs/images/` — LINEで送れる画像版（受診ガイド8枚・動画案内4枚）

GitHub Pages で `docs/` を公開しています。

## 情報の出どころ

- 横浜市立大学附属市民総合医療センター 公式サイト（ペインクリニック内科・初診予約）
- 同センター 外来診療担当医表（2026年8月1日現在）
- ＆慢性痛（横浜市立大学）掲載の集学的痛みセンター一覧
- YouTube チャンネル「慢性の痛み講座 北原先生の痛み塾」公式フィード

診療体制・予約方法・担当曜日は変わります。受診前に必ず病院へ電話で確認してください。

## 素材

- `src/sheets.html` — 受診ガイド画像の生成元
- `src/sheets-video.html` — 動画案内画像の生成元（`src/qr/` はQRコード）

画像は Edge のヘッドレスで 1080×1440 に書き出し、8分割・4分割しています。
